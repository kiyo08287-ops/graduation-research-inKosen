# Keypoint R-CNNおよびTCNに基づく3次元姿勢推定を用いた単眼RGB映像からの関節モーメントの算出

## 研究背景
近年、増加傾向にあるトレーニング人口に伴って、トレーニングにより怪我をしてしまう事例が増えている。
特に、一人でトレーニングする方や、初心者の方にとっては、自分のフォームが正しいかが分からず、怪我をするリスクが高まっている。

そこでパーソナルトレーニングなどの費用の掛かるものではなく、手軽に利用できる、**単眼カメラでの姿勢評価システムの作成**を目標とする。

## システム概要
単眼RGB映像から3次元の骨格を推定し、得られた骨格座標を用いて筋骨格モデルによるシミュレーションを行います。

### 1. 骨格推定
映像からの骨格推定に、2D姿勢推定と2D-to-3Dリフティングからなる2段階のアプローチを採用しました。

- **2D姿勢推定**: COCOデータセット学習済みの **Keypoint R-CNN (Detectron2)** を採用し、各フレームに対して17点の関節座標のキーポイント検出を行います。
- **2D-to-3Dリフティング**: 時間的畳み込みネットワーク（TCN）を用いて、Human3.6Mデータセットで学習されたモデル（**VideoPose3D**）を採用しました。

### 2. 負荷計算
得られた3次元関節座標データを用いて **OpenSim** で筋骨格モデルのスケーリング、逆運動学（IK）計算、逆動力学（ID）計算を行い、各関節にかかるトルクを算出します。

## 実行環境

- **ベース環境**: Windows 11 (WSL2 / Ubuntu)
- **環境管理**: Miniconda3
- **GPU**: NVIDIA GeForce RTX 4060 (CUDA 12.1.105)

依存関係の衝突を避けるために、タスクごとに Anaconda 仮想環境を個別に作成して実行しました。

#### 🔹 骨格推定環境
- **言語**: Python 3.8.12
- **主なツール**: Detectron2, VideoPose3D (PyTorch)

#### 🔹 負荷計算環境
- **言語**: Python 3.8.20
- **主なツール**: OpenSim Python API
